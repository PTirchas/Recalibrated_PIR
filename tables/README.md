# Output tables

All files are generated by `analytics.rm_pir_analysis` or `analytics.technical_robustness` unless noted otherwise.

Core rolling analysis:

- `rolling_validation_summary.csv`: seasonal and pooled W/T/L counts, discordance rates, intervals, and paired changes.
- `paired_transitions.csv`: both-concordant, official-only, RM-PIR-only, and both-discordant transitions.
- `rolling_game_results.csv`: auditable game-level official and RM-PIR contrasts.
- `model_registry.csv`, `rolling_coefficients.csv`, `nested_tuning_grid.csv`: calibration windows, selected models, locked coefficients, and tuning results.
- `coefficient_bootstrap_intervals.csv`, `coefficient_bootstrap_target_performance.csv`: conditional coefficient and target-performance uncertainty.

Descriptive outputs:

- `e2025_players.csv`: all 335 eligible player totals and ranks.
- `e2025_teams_regular_season.csv`, `e2025_teams_all_stages.csv`: team totals, per-game values, and ranks.

Integrity and sensitivity outputs:

- `data_integrity_audit.csv`, `event_comparability_diagnostics.csv`, `optimization_audit.csv`, `residual_component_audit.csv`, `residual_identity_audit.csv`.
- `sensitivity_summary.csv`, `sensitivity_tuning_grid.csv`, `team_dependence_sensitivity.csv`, `group_restriction_diagnostics.csv`.
- `tie_sensitivity.csv`, `scale_anchor_sensitivity.csv`, `player_scale_sensitivity.csv`, `tuning_tie_sensitivity.csv`, `fixed_origin_transport.csv`.
- `club_membership_bootstrap.csv`, `joint_uncertainty_bootstrap.csv`, `player_association_diagnostics.csv`, `player_association_bootstrap.csv`.

Provenance:

- `analysis_provenance.csv`: timing and classification of analysis decisions.
- `data_exclusions.csv`: auditable exclusions and scope restrictions.
- `analysis_manifest.json`: software versions, seeds, tolerances, replicate counts, and SHA-256 input/output hashes.
